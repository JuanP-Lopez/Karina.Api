<h1 align="center"><b>Welcome to Project Karina </b></h1>
<p align="center">Active Development</p>

<h3 align="center"> AI Assistant | Messaging Integration | Web Platform </h3>
<p align="center">
  <em>
    An AI-powered assistant designed to simplify digital interactions through messaging, web technologies, and intelligent automation.
    Karina is an integrated assistant platform that combines artificial intelligence, messaging services, and web technologies into a unified solution.
  </em>
  
  <em>
    The project aims to make AI more accessible through familiar interfaces, while providing a foundation for personalized interactions, contextual conversations, and future automation capabilities
    Rather than being a standalone chatbot, Karina is built as a modular ecosystem in which multiple components work together to deliver a unified experience.
  </em> 
</p>

## Overview
<div>

  <p>
    Karina provides multiple ways to interact with an AI-powered assistant:
  </p>
    <ul>
      <li>WhatsApp Integration: Interact with the assistant through WhatsApp using the WhatsApp Cloud API.</li>
      <li>Web Platform: A web-based interface for accessing the assistant and additional user-oriented features.</li>
      <li>AI Agent: An independent agent responsible for processing user requests and generating intelligent responses.</li>
      <li>Backend Services: A centralized API responsible for communication, application logic, data management, and integration between components.</li>
    </ul>
  <p>All components belong to the same project and are designed to work together.</p>

  ## Repositories

  Karina is composed of three interconnected repositories.
  Each one is responsible for a specific component of the platform:
  
  | Repository | Description |
  |---|---|
  | [Karina Backend](https://github.com/JuanP-Lopez/Karina.Api) | Central API, application logic, authentication, and data management. |
  | [Karina Web](https://github.com/JuanP-Lopez/web) | Web interface, user authentication, and assistant interaction. |
  | [Karina Agent](https://github.com/JuanP-Lopez/karina_agent) | AI agent implementation and intelligent request processing. |
  
  All repositories are part of the same project and work together
  to provide a unified assistant experience.

  ## Key Features

  <ul>
    <li>AI-powered conversational interactions.</li>
    <li> WhatsApp-based assistant access.</li>
    <li>Dedicated web platform.</li>
    <li>User registration and authentication.</li>
    <li>Conversation and message management.</li>
    <li>Persistent data storage.</li>
    <li>Modular architecture for future integrations.</li>
    <li>Features are continuously evolving as the project progresses.</li>
  </ul>
